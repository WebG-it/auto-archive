## Auto Archive 1.0.1

Description and guides: **why it exists**. No change in behaviour.

- The description shown in *System > Extensions* (English and Italian) now says what the plugin is for:
  archived articles in a category of their own, **archiving moves, moving archives**, 301 redirect when
  the address changes.
- The user guides ([USAGE](https://github.com/WebG-it/auto-archive/blob/main/docs/autoarchive/USAGE.md),
  [USO](https://github.com/WebG-it/auto-archive/blob/main/docs/autoarchive/USO.md)) and the README explain
  why the archive lives in a category and not only in the Archived state, and that
  *Archive Layouts for YOOtheme* alone is enough to design an archive page, even two distinct archives
  filtered by category.

Update from *System > Update > Extensions*, or install `plg_system_autoarchive-1.0.1.zip` with
*System > Install > Extensions > Upload Package File*.
